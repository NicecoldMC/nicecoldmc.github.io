Install in a minute

STEP 1

Get Iris

Install Iris for your Minecraft version. Sodium is recommended with it. You can also use OptiFine instead.

STEP 2

Add the shader pack

Download Hollow Shaders from Modrinth, or add it from the content tab of the Modrinth App. If you downloaded a .zip, put it in your shaderpacks folder without unzipping it.

STEP 3

Turn it on

In Minecraft, open Options, then Video Settings, then Shader Packs. Pick Hollow Shaders from the list and apply.

Questions

Which Minecraft versions are supported?

Minecraft Java 1.21.11 and 26.1.x to 26.3. Pick the file that matches your version on the Versions tab of the Modrinth page.

How heavy is it?

The pack is written with performance in mind and is tagged for low-end systems, but your FPS still depends on your hardware. If it runs badly, lower your render distance first. If it still struggles, open an issue and include your GPU.

Do I need Iris?

Iris is the recommended way to run it. The pack also supports OptiFine.

Can I use it in videos and screenshots?

Please credit Hollow Shaders when you do. The pack uses the CC BY-NC 4.0 license, which does not allow commercial use, so read the license text if you plan to do more than share screenshots.

I found a bug. Where do I report it?

Open an issue on GitHub and include your Minecraft version, your GPU and a screenshot if you can.
